Developer Reference Manual

PingDartDB Command Cheat Sheet

Search and filter every operational command: Installation, CLI, SQL DDL/DML, Document NoSQL, Vectors, Clustering, and Migrations.

Install PingDartDB (Linux One-Liner)

Bash / Root

Compiles binaries, creates dedicated pingdart user, FHS paths, and registers systemd service.

git clone https://github.com/pingdart/ClusterDB.git pingdartdb && cd pingdartdb && chmod +x install.sh && sudo ./install.sh

Check Systemd Service Status

Linux Systemd

Inspect daemon uptime, PID, memory consumption, and recent log messages.

sudo systemctl status pingdartdb

Start / Stop / Restart Service

Linux Systemd

Cleanly manage the PingDartDB service lifecycle.

sudo systemctl start pingdartdb sudo systemctl stop pingdartdb sudo systemctl restart pingdartdb

Live Daemon Journal Logs

Linux Systemd

Stream live stdout/stderr logs from the background database engine.

sudo journalctl -u pingdartdb -f

Safe Upgrade with Rollback

Bash / Upgrade

Takes an ACID snapshot, compiles & verifies health; rolls back automatically on failure.

cd pingdartdb && git pull origin main && sudo ./upgrade.sh

Safe Uninstallation

Bash / Root

Removes systemd services and binaries while preserving data safely by default.

sudo ./uninstall.sh

View Encrypted Vault Credentials

Terminal Vault

Decrypts and displays root credentials in-memory using the 4-8 digit Security PIN.

pingdart-vault view

Rotate Password or Security PIN

Terminal Vault

Authenticates with current PIN and re-encrypts the vault with new credentials.

pingdart-vault rotate

Node Registration Telemetry API

Node.js REST

Central Node.js API registering cluster node OS, IPs, and hardware identity (zero passwords/PINs).

curl -X POST https://api.chat.pingdart.com/api/database/install-registration \ -H "Content-Type: application/json" \ -d '{"installation_id": "UUID", "email": "admin@pingdart.com", "os_distro": "ubuntu"}'

Interactive MySQL-Style CLI

Terminal CLI

Opens interactive REPL session with auto-cached session token and ASCII tabular formatting.

pingdart

Check Cluster & Node Status

Terminal CLI

Displays engine version, leader node ID, active nodes, and storage directory.

pingdart status

Connect to Custom Host & Port

Terminal CLI

Specify target remote or local PingDartDB instance endpoint.

pingdart -h 127.0.0.1 -P 4650

Execute SQL Query (Batch Mode)

Terminal CLI

Runs query directly in headless scripts or CI/CD pipelines.

pingdart -e "SHOW DATABASES;"

Create User with IP Whitelist

SQL DDL

Support for both MySQL 'user'@'host' syntax and explicit IP / subnet whitelist patterns.

CREATE USER 'backend'@'192.168.1.%' PASSWORD 'Pass456!'; CREATE USER developer PASSWORD 'Secret123!' IP '192.168.1.50';

Grant Database Privileges

SQL DDL

Grant ALL, READ, or WRITE privileges on a designated database catalog.

GRANT ALL ON ecommerce_prod TO 'backend'@'192.168.1.%'; GRANT READ ON production_db TO reporting_user;

Update Password & Whitelist

SQL DDL

Atomically update credential password and network access mask.

ALTER USER developer PASSWORD 'NewPass2026!' IP '10.0.0.%';

Revoke / Drop User

SQL DDL

Deletes credentials and invalidates active session tokens immediately.

DROP USER 'developer'@'localhost';

Create & Switch Database Catalog

SQL DDL

Namespace multi-tenancy catalogs with instant zero-cost database switching.

CREATE DATABASE analytics; USE analytics; SHOW DATABASES;

Create Table with Strict Types

SQL DDL

Define strongly-typed tables. Supports INT, BIGINT, FLOAT, VARCHAR, TEXT, BOOLEAN, TIMESTAMP, VECTOR.

CREATE TABLE users ( id INT PRIMARY KEY, name VARCHAR(100), email VARCHAR(150), balance FLOAT, created_at TIMESTAMP );

Inspect Schema (DESCRIBE / SHOW)

SQL DDL

List active tables and inspect column datatypes, primary keys, and constraints.

SHOW TABLES; DESCRIBE users;

Create Secondary B-Tree Index

SQL DDL

Accelerate point lookups and range scans with B-Tree indexes.

CREATE INDEX idx_users_email ON users (email);

Collect CBO Statistics

SQL DDL

Computes HyperLogLog NDV cardinality and typed histograms for the Cost-Based Optimizer.

ANALYZE TABLE users;

Insert Records

SQL DML

Insert single or multiple rows into relational tables.

INSERT INTO users (id, name, email, balance) VALUES (1, 'Alice', 'alice@corp.com', 2500.00);

Filter, Sort & Paginate (SELECT)

SQL DML

Standard SELECT projection with WHERE filters, ORDER BY, and LIMIT/OFFSET.

SELECT id, name, balance FROM users WHERE balance >= 1000.00 ORDER BY balance DESC LIMIT 10 OFFSET 0;

Update & Delete Records

SQL DML

Mutate records matching predicate conditions.

UPDATE users SET balance = 3000.00 WHERE id = 1; DELETE FROM users WHERE balance < 0;

EXPLAIN & EXPLAIN ANALYZE

SQL Profiling

Live query execution profiler displaying recursive PlanNode timings in microseconds.

EXPLAIN ANALYZE SELECT * FROM users WHERE email = 'alice@corp.com';

Obtain Session Token (REST Login)

REST HTTP

Returns UUID session token used for subsequent REST calls.

curl -X POST http://localhost:4650/login -H "Content-Type: application/json" -d '{"username": "admin", "password": "admin123"}'

Query Document Collection (POST /document/query)

REST HTTP

Document NoSQL querying without needing SQL string concatenation.

curl -X POST http://localhost:4650/document/query -H "Content-Type: application/json" -d '{"token": "TOKEN", "collection": "users", "where": [{"field": "city", "operator": "==", "value": "Hyderabad"}], "limit": 20}'

Register Embedding Model Primitive

AI SQL

Register local or remote AI embedding models directly into the database catalog.

CREATE EMBEDDING MODEL fast_embed TYPE='local' DIMENSION=384 VERSION='1.0';

Auto-Generated Vector Column

AI SQL

PingDart automatically derives and indexes vectors on every insert or update.

CREATE TABLE docs ( id INT PRIMARY KEY, content TEXT, embedding VECTOR(384) GENERATED FROM content USING fast_embed );

Natural Language Semantic Match

AI SQL

Sub-millisecond high-dimensional HNSW cosine vector proximity search.

SELECT content, SEMANTIC_MATCH(content, 'database engine') AS score FROM docs WHERE SEMANTIC_MATCH(content, 'database engine') > 0.40 ORDER BY score DESC;

Launch Seed Leader Node

Cluster Daemon

Starts cluster leader node on port 4650 with local persistent storage.

cargo run --release --bin pingdart-core -- --port 4650 --node-id node-1 --data-dir ./data_node1

Join Follower Node to Cluster

Cluster Daemon

Follower joins existing cluster, participates in Raft consensus and hash sharding.

cargo run --release --bin pingdart-core -- --port 4651 --node-id node-2 --join 127.0.0.1:4650 --data-dir ./data_node2

Export Protobuf (.pb) Backup

Backup SQL

Canonical Protocol Buffers export with Zstandard compression and optional AES-256-GCM encryption.

EXPORT DATABASE ecommerce_prod TO 'backups/ecommerce_prod.pb'; EXPORT DATABASE ecommerce_prod TO 'backups/enc.pb' ENCRYPTED KEY 'SecretKey!';

Import / Restore Database Snapshot

Backup SQL

Verifies SHA-256 integrity checksum before restoring tables, indexes, and schemas.

IMPORT DATABASE FROM 'backups/ecommerce_prod.pb';

Universal Migration from MySQL / Postgres

Migration SQL

Streams legacy SQL dumps directly into PingDart with automatic schema drift handling.

MIGRATE FROM 'mysql' FILE 'dump.sql' TO TABLE 'mysql_data' SCHEMA_POLICY ADD_MISSING_COLUMNS; MIGRATE FROM 'postgres' FILE 'pg_dump.sql' TO TABLE 'pg_data' SCHEMA_POLICY STRICT;

Universal Migration from MongoDB / CSV

Migration SQL

Unpacks MongoDB extended JSON or CSV with inline AI vector generation.

MIGRATE FROM 'mongodb' FILE 'customers.json' TO TABLE 'mongo_clients' SCHEMA_POLICY ADD_MISSING_COLUMNS; MIGRATE FROM 'csv' FILE 'data.csv' TO TABLE 'articles' EMBED content AS embedding DIM 384;

Core Capabilities & Architecture

Every Database Capability You Need, Built Into One Binary

Eliminate sprawling infrastructure stacks. PingDart DB replaces separate databases for SQL, vector embeddings, caching, graphs, and full-text search.

AI & RAG

Sub-Millisecond HNSW Vector Engine

High-dimensional proximity graph supporting Cosine, Euclidean, and Dot Product ANN search across 384 to 3072 dimensions in sub-millisecond P50.

AI Automation

First-Class Model Registry & Auto-Embeddings

Define columns using 'VECTOR GENERATED FROM text USING model'. Never manage float vectors or external embedding services manually.

Agent Memory

Cognitive AI Memory (Ebbinghaus Decay)

Hierarchical memory (Working, Episodic, Semantic, LongTerm) with Ebbinghaus exponential decay ranking and automatic memory consolidation.

Hybrid Search

BM25 & Vector Hybrid Search

Combines dense HNSW vector similarity with BM25 inverted keyword search using normalized α-weighted rank fusion.

Graph Database

Neo4j-Style Labeled Property Graph

Multi-labeled nodes, typed directional relationships (WORKS_AT, KNOWS), and breadth-first search (BFS) shortest-path traversals.

AI Protocol

Native Model Context Protocol (MCP)

Built-in JSON-RPC 2.0 stdio MCP server for direct zero-code integration with Claude Desktop, Cursor, Antigravity, and LangChain agents.

Multi-Model

Unified SQL + Document NoSQL

One engine for relational schemas, strict DDL types, and JSON document collections. No need to manage separate Postgres and MongoDB clusters.

Clustering

Raft Consensus Clustering & Sharding

Multi-node consensus with automatic leader election, 16-virtual-node consistent hash ring, and distributed scatter-gather vector queries.

HTAP Engine

Vectorized Columnar Analytics (OLAP)

SIMD-optimized contiguous memory chunk arrays supporting grouped aggregations (COUNT, SUM, AVG, GROUP BY) at 118,700+ rows/sec.

Query Optimizer

Cost-Based Query Optimizer (CBO)

Postgres-grade optimizer using HyperLogLog (HLL) NDV cardinality, typed equi-depth histograms, and calibrated cost weights.

Observability

OpenTelemetry Tracing & EXPLAIN ANALYZE

Live query execution profiling with recursive PlanNode trees, stage microsecond breakdown, and native OTLP export to Jaeger/Datadog.

Security

Zero-Leak Row-Level Security (RLS)

Injected dynamically into SELECT pipelines using CURRENT_TENANT() and CURRENT_USER() policies for leak-proof multi-tenancy.

Encryption

AES-256-GCM Envelope Encryption

Authenticated encryption at rest using unique 96-bit nonces, PBKDF2/SHA-256 key derivation, and Poly1305 tamper detection.

Access Control

Granular RBAC & Revocable API Keys

20 atomic permissions, preloaded roles (SuperAdmin, DataScientist, AppDeveloper), and high-entropy API keys with instant revocation.

Zero-Friction

Universal Migration Framework

Stream live data from PostgreSQL, MySQL, MongoDB, CSV, and JSON with automated schema drift handling and crash checkpoints.

Disaster Recovery

Protobuf (.pb) ZSTD Backup & PITR

Canonical Protocol Buffers schema, dictionary Zstandard compression (3x-5x smaller), and CDC commit log Point-In-Time Recovery.

Storage Tiering

Cloud Object Storage Tiering

Async ObjectStore tier supporting AWS S3, Cloudflare R2, MinIO, and Local Filesystem for snapshot offloading and cold archiving.

Kubernetes

Cloud-Native Kubernetes Operator

Custom Resource Definition (CRD), HA StatefulSet manifests, pod anti-affinity, and automated Prometheus /metrics endpoint.
